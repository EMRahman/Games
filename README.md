# Side Quest

A small, dependency-free collection of browser games built for desktop, iPhone, and iPad.

## [Play the games →](https://emrahman.github.io/Games/)

Choose a title from the quick-launch arcade menu or browse the full game library:

- **Northstar** — fleet-hunting sea battle for one or two players
- **Driftbelt** — momentum-based space arcade action
- **Fourfold** — two-player four-in-a-row
- **Kado** — two-player Go with multiple board sizes
- **Boxed In** — two-player Dots and Boxes on adjustable grids
- **Linefall** — falling-block puzzle with hold, next queue, ghost piece, and combos
- **Recall Club** — memory matching for one or two players
- **Neon Coil** — a glowing, free-moving Snake remix
- **Pocket Snake** — old-school Snake on an 84 × 48 monochrome screen
- **Conquest** — world-domination strategy on an original 49-territory map for 1–6 players against computer opponents or friends on one device
- **Landlord** — property trading for 2–6 players, with auctions, trades, and computer opponents
- **Iron Routes** — railway building for 2–5 players across an original 41-city network, with computer opponents

No installation, account, build step, or external dependency is required. Each game is a self-contained HTML file with mouse, keyboard, and touch support where appropriate.

## Run locally

Open `index.html` directly in a modern browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
